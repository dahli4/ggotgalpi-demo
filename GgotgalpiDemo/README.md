# 꽃갈피 데모

SwiftUI로 만든 꽃갈피 초기 데모입니다.

## 실행 방법

1. `GgotgalpiDemo.xcodeproj`를 Xcode로 엽니다.
2. 상단 실행 기기에서 iPhone 시뮬레이터를 선택합니다.
3. `Run` 버튼을 누릅니다.

책과 감상 기록은 SwiftData로 기기에 저장됩니다. 앱을 종료한 뒤 다시 실행해도 추가·수정한 내용이 유지됩니다.

## 데모에 들어간 화면

- 책장: 샘플 책, 분야 필터, 책 추가
- 달력: 읽은 날짜와 표지 표시, 날짜별 기록 확인
- 기록: 최근 감상과 간단한 독서 통계
- 책 상세: 회독 수, 페이지, 감상 기록
