# 꽃갈피 앱

## 실행 방법

1. `GgotgalpiDemo.xcodeproj`를 Xcode로 엽니다.
2. 상단 실행 기기에서 iPhone 시뮬레이터를 선택합니다.
3. `Run` 버튼을 누릅니다.

책과 감상 기록은 SwiftData로 기기에 저장됩니다. 앱을 종료한 뒤 다시 실행해도 추가·수정한 내용이 유지됩니다. Apple 측 준비를 마치면 iCloud 동기화도 사용할 수 있습니다.

## 데모에 들어간 화면

- 책장: 책 정렬, 분야 필터, 책 추가와 작가 즐겨찾기
- 달력: 읽은 날짜와 표지 표시, 날짜별 기록 확인
- 기록: 최근 감상, 문장, 별점과 휴지통
- 책 상세: 회독 수, 페이지, 감상 기록

새 저장소에는 예제 기록을 자동으로 넣지 않습니다. QA에서만 실행 인자 `-seed-sample-data`로 예제를 넣을 수 있습니다.

동기화 범위와 제한, Apple 측 준비, 두 기기 검증 순서는 [저장소 README](../README.md), 자동 검사 방법은 [테스트 안내](../Tests/README.md)에 있습니다. 실제 빌드 소스는 `App/`, `Core/`, `Features/` 아래입니다.
